# Task Manager

A full-stack task management application built using the MERN stack that helps users manage daily tasks efficiently. Users can create tasks, mark them as completed, and receive email reminders one day before the task due date.

---

## Features

- User Authentication (Login / Signup)
- Create, update, and delete tasks
- Mark tasks as completed
- Redux state management
- Email reminders before task due date
- Responsive user interface
- Task completion tracking



## Tech Stack

### Frontend
- React.js
- Redux Toolkit
- Material UI
- Typescript
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other Tools
- JWT Authentication
- Nodemailer
- Cron job


## Main Functionalities

### Authentication
- Secure user signup and login using JWT authentication.

### Task Management
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed

### Email Reminder System
Users receive an automatic email reminder one day before the due date of a task.
